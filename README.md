# Student Management System (Java)

A console-based Java application to manage student records. This project demonstrates Object-Oriented Programming (OOP) principles and basic File I/O in Java.

## 🚀 Features
- **Add Students:** Register new students with a unique ID.
- **Update Records:** Modify name, age, or department for existing students.
- **Delete Records:** Remove student entries using their ID.
- **Search:** Quickly find student details by ID.
- **Data Persistence:** Save your list to a text file and load it automatically on startup.

## 🛠️ Tech Stack
- **Language:** Java
- **Tools:** Scanner (for input), ArrayList (for data storage), File I/O (for persistence).

## 📂 Project Structure
- `Student.java`: The data model.
- `StudentManager.java`: The logic controller for managing the student list.
- `Main.java`: The user interface and menu loop.
